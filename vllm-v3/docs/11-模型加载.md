# 快速权重加载

> 对应 v3 的加载性能优化：4B 模型权重加载从 ~29s 降到 ~3.9s。

模型加载慢在三个环节：① 构造模型时的随机初始化（马上会被覆盖，纯浪费）；② 默认 fp32 构造再转 dtype（中间态显存翻倍 + 转换开销）；③ safetensors 分片逐个字段读（磁盘 I/O 与 CPU 拷贝串行）。`compute/models/loader.py` 逐一解决。

## 一、跳过随机参数初始化：`skip_param_init`

```python
@contextmanager
def skip_param_init():
    orig_linear = nn.Linear.reset_parameters
    orig_embed = nn.Embedding.reset_parameters
    nn.Linear.reset_parameters = lambda self: None
    nn.Embedding.reset_parameters = lambda self: None
    try:
        yield
    finally:
        nn.Linear.reset_parameters = orig_linear
        nn.Embedding.reset_parameters = orig_embed
```

权重随后由 `load_model` 覆盖，先分配随机数是纯浪费（4B 模型约 24s）。临时替换 `reset_parameters`，构建完自动恢复。

## 二、目标 dtype 直接构建：`default_dtype_context`

```python
@contextmanager
def default_dtype_context(dtype):
    prev = torch.get_default_dtype()
    torch.set_default_dtype(dtype)
    try:
        yield
    finally:
        torch.set_default_dtype(prev)
```

在目标 dtype（如 bf16）下构建模型，省去 fp32 中间态——显存减半、无 dtype 转换。

## 三、整分片读取 + 后台预取：`safetensors_weights_iterator`

```python
def safetensors_weights_iterator(hf_folder):
    files = sorted(glob.glob(os.path.join(hf_folder, "*.safetensors")))
    if len(files) == 1:
        yield from _load_shard_cpu(files[0])
        return
    with concurrent.futures.ThreadPoolExecutor(max_workers=1) as pool:
        fut = pool.submit(_load_shard_cpu, files[0])
        for i, _st_file in enumerate(tqdm(files, desc="Loading weights")):
            items = fut.result()
            if i + 1 < len(files):
                fut = pool.submit(_load_shard_cpu, files[i + 1])   # 预取下一分片
            yield from items
```

`load_file` 整分片读入内存，并用单线程池在消费当前分片时**后台预取下一分片**，磁盘 I/O 与 CPU 拷贝重叠。

## 四、加载入口与权重融合

```python
def load_model(model, hf_folder):
    model.load_weights(safetensors_weights_iterator(hf_folder))
    return model.eval()
```

`load_weights`（`compute/models/qwen3.py`）在加载时做 GEMM 融合的权重对齐：

- **q/k/v → qkv_proj**：把 HF 的 `q_proj/k_proj/v_proj` 按 `q_size/kv_size/kv_size` 的偏移拼进 `qkv_proj`；
- **gate/up → gate_up_proj**：把 `gate_proj` 与 `up_proj` 沿 dim 0 拼接进 `gate_up_proj`；
- **lm_head 复用 embed 权重**：`lm_head.weight` 直接复用 `embed_tokens.weight`（tied embedding），省一次拷贝。

未被加载的参数会打印告警，方便排查命名不匹配。

## 五、小结

| 环节 | 手段 | 收益 |
| --- | --- | --- |
| 随机初始化 | `skip_param_init` 替换 `reset_parameters` | 省 ~24s（4B） |
| dtype 转换 | `default_dtype_context` 目标 dtype 直建 | 显存减半、免转换 |
| 分片读取 | `load_file` 整分片 + 单线程预取 | 磁盘 I/O 与拷贝重叠 |
| 权重融合 | qkv / gate_up / tied embedding | 与算子融合配套 |
