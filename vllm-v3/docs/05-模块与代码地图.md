## 1. 三面（与 v2 同构）

```text
Engine → Scheduler（控制，合同≈v2）
       → KVManager / memory（资源 + 写）
       → ModelRunner（数据面：v3 主改动）
```

---

## 2. 为何 `kv/` + `pagedattention/` → `memory/`

| v2 | v3 | 说明 |
| --- | --- | --- |
| `kv.*` 编排 | `memory.manager` 等 | 页表 + 池统一 |
| `PagedStore.write` | `kv_ops.store_kvcache` | Triton 写 |
| `PagedStore.gather` | **删除** | FlashInfer 就地读（打掉瓶颈 A） |

逻辑合同仍是 `block_table` / `slot_mapping`；变的是读路径实现。详见曾用文档意图：教学从「看见 gather」变为「接工业 Attention」。
