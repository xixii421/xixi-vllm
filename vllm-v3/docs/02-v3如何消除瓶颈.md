# 02 · v3 如何消除 v2 的性能瓶颈

本文与 [01-v2性能瓶颈](./01-v2性能瓶颈.md) **一一对应**：每个瓶颈 → v3 改法 → 代码位置。  
**不改调度语义**，只换数据面。

---

## 对照总表

| 瓶颈 | v2 | v3 做法 | 关键路径 |
| --- | --- | --- | --- |
| A Attention | gather + SDPA | FlashInfer paged run | `layers/attention*.py` |
| B Decode launch | eager | 可选 CUDA Graph | `core/cuda_graph.py` |
| C KV 写 | index_copy_ | Triton `store_kvcache` | `memory/kv_ops.py` |
| D 层内算子 | PyTorch | Triton Norm/RoPE；compile Silu | `layers/{layernorm,rotary,activation}.py` |
| E 输入/采样 | 偏同步 | pin_memory + 批量 Sampler | `engine/input_builder.py`, `sampler.py` |
| F 前缀 | radix 残缺等 | 完整 APC + 树/页驱逐 | `memory/prefix/`, `block_manager.py` |
| G 双 forward | 两次 | **仍两次**（教学保留） | `model_runner.run` |

---

## A → FlashInfer：去掉 gather

```text
v2:  write → gather → SDPA
v3:  Triton store_kvcache → wrapper.run(q, paged_kv)
```

- Prefill：`BatchPrefillWithPagedKVCacheWrapper` + `cu_seqlens`  
- Decode：`BatchDecodeWithPagedKVCacheWrapper`  
- 池布局：`[2, L, blocks, block_size, Hkv, D]`（NHD）

**效果**：打掉带宽与 kernel 双税；批 decode 真正合批进一个 attention 后端。

旋钮（默认开，eager 约 +20% 量级）：

- `flashinfer_use_tensor_cores`  
- `flashinfer_non_blocking`  

---

## B → Decode CUDA Graph：去掉 launch 税

- 默认 `enforce_eager=True`（安全）  
- 打开：`enforce_eager=False` / `--compile`  
- 按 batch 阶梯 capture；replay 前仍 `plan`（FlashInfer 约束）

**效果**：小模型 decode 数量级提升。  
Prefill 仍 eager（shape 不稳定）。

---

## C → Triton KV 写

`store_kvcache(key, value, k_cache, v_cache, slot_mapping)`  
按 token 写扁平 slot，对齐 FlashInfer 布局。

---

## D → 层内融合 / compile

| 模块 | v3 |
| --- | --- |
| RMSNorm | Triton，可 fused residual |
| RoPE | Triton in-place |
| SiluAndMul | `torch.compile` |

---

## E → 输入与采样

- `pin_memory` + `non_blocking` H2D  
- Sampler 一次处理整 batch 温度 / top-p 等  

---

## F → APC 补齐（有效性能）

| 项 | v3 |
| --- | --- |
| Hash | xxhash + **页池 LRU** |
| Radix | invalidate/dedup/pin + **树叶 evict 接到 allocate** |
| Chunked | 与 v2 同合同；未完成 chunk 可跳过 LM-head |
| Full-hit | promote → decode（不卡 waiting） |

详见 [04-前缀APC](./04-前缀APC.md)。  
**注意**：同命中时 hash≈radix 的 GPU 时间；差在压力下谁还能命中。

---

## G → 有意未改

```text
ModelRunner.run(prefills, decodes):
    decode_forward(...)
    prefill_forward(...)
```

Fused PD / 多 stream 重叠属于 **下一阶段**，不是「相对 v2 必须先做完」的清单。见 [optimization_guide.md](./optimization_guide.md)。

## 资源层命名（附带整理，非主性能）

v2：`kv/` + `pagedattention/`（含 gather）  
v3：`memory/`（池 + 写 + 前缀）；读由 FlashInfer 完成。  

逻辑合同不变，见 [05-模块与代码地图](./05-模块与代码地图.md)。
