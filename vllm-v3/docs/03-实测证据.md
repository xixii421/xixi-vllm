# 实测证据：v2 vs v3 性能对比分析

> 测试日期：2026-07-26
> GPU：NVIDIA GeForce RTX 4090 D (24 GB)
> CUDA 版本：13.0
> PyTorch 版本：2.6.0 (torch.compile 模式)

## 测试配置


| 配置                 | v2_eager | v3_eager         | v3_cudagraph     |
| ------------------ | -------- | ---------------- | ---------------- |
| 引擎版本               | vllm-v2  | vllm-v3          | vllm-v3          |
| KV Block Size      | 16       | 256 (FlashInfer) | 256 (FlashInfer) |
| Enforce Eager      | True     | True             | **False**        |
| CUDA Graph         | 否        | 否                | **是**            |
| Context Length     | 2048     | 4096             | 4096             |
| Max Num Seqs       | 8        | 8                | 8                |
| Max Batched Tokens | 4096     | 8192             | 8192             |
| GPU Memory Util    | 自动       | 0.85             | 0.85             |
| Prefix Cache       | 无        | 无                | 无                |


> 注：v2_compile 模式因与当前 PyTorch 2.6.0 的 `cudagraph_trees` 存在冲突（PageAttention `index_copy`_ mutated inputs），无法完成完整的 benchmark，已排除。



## 测试指标

- **TTFT**：首 token 延迟（越小越好）
- **Decode**：解码吞吐（tokens/s，越大越好）
- **E2E**：端到端吞吐（tokens/s，越大越好）
- **Concurrency**：多并发场景下的吞吐（tokens/s，越大越好）

测试 prompt 为 ~266 tokens 的英文文本，覆盖 1/32/128/256 四种生成长度。

## Qwen3-0.6B 测试结果



### 1. 引擎初始化时间


| 版本           | Init Time | 相对 v2 |
| ------------ | --------- | ----- |
| v2_eager     | 7.63s     | 1.00x |
| v3_eager     | 9.92s     | 1.30x |
| v3_cudagraph | 8.83s     | 1.16x |


> v3 初始化略慢于 v2，主要原因是 v3 使用了更复杂的 KV cache 管理（FlashInfer block_size=256 分配策略）以及额外的 CUDA Graph 预热。



### 2. 单请求 TTFT


| Token 长度 | v2_eager | v3_eager | v3_cudagraph |
| -------- | -------- | -------- | ------------ |
| TTFT_1   | 24.75ms  | 21.07ms  | 20.19ms      |
| short_32 | 24.33ms  | 21.47ms  | 20.24ms      |
| med_128  | 24.21ms  | 20.48ms  | 20.21ms      |
| long_256 | 24.18ms  | 20.40ms  | 20.45ms      |


> v3 的 TTFT 比 v2 低约 **15-18%**（~20ms vs ~24ms）。值得一提的是 v3 的 TTFT 在不同 prompt 长度下保持稳定，说明 FlashInfer 的 prefill kernel 效率很高。CUDA Graph 对 TTFT 影响不大（prefill 本身不是 decode 循环，CG 不加速 prefill）。



### 3. 单请求 Decode / E2E 吞吐


| Token 长度 | 指标     | v2_eager | v3_eager | v3_cudagraph  |
| -------- | ------ | -------- | -------- | ------------- |
| short_32 | Decode | 36.6 t/s | 57.0 t/s | **415.2 t/s** |
| short_32 | E2E    | 36.8 t/s | 56.5 t/s | **337.5 t/s** |
| med_128  | Decode | 36.8 t/s | 57.8 t/s | **415.4 t/s** |
| med_128  | E2E    | 36.9 t/s | 57.7 t/s | **391.9 t/s** |
| long_256 | Decode | 37.0 t/s | 58.0 t/s | **414.1 t/s** |
| long_256 | E2E    | 37.1 t/s | 57.9 t/s | **402.3 t/s** |


> **关键发现：**
>
> - v3_eager 的 decode 吞吐是 v2_eager 的 **1.56x**（~58 vs ~37 tok/s），原因是 FlashInfer 的 block_size=256 比 v2 的 block_size=16 大 16 倍，每次 step 处理更多 token，减少 Python 调度开销。
> - v3_cudagraph 的 decode 吞吐是 v3_eager 的 **7.1x**（~415 vs ~58 tok/s），原因是 CUDA Graph 消除了 decode 循环中的 Python 调度和 kernel launch 开销。
> - v3_cudagraph 的 decode 吞吐是 v2_eager 的 **11.2x**（~415 vs ~37 tok/s）。



### 4. 多并发吞吐


| Batch Size | v2_eager  | v3_eager  | v3_cudagraph   |
| ---------- | --------- | --------- | -------------- |
| 1          | 37.0 t/s  | 57.9 t/s  | **391.7 t/s**  |
| 2          | 62.6 t/s  | 100.7 t/s | **645.8 t/s**  |
| 4          | 96.4 t/s  | 201.7 t/s | **1262.5 t/s** |
| 8          | 144.9 t/s | 397.2 t/s | **2385.0 t/s** |


> **并发 Scale-up：**
>
> - v2_eager: batch1→batch8 提升 3.9x
> - v3_eager: batch1→batch8 提升 6.9x
> - v3_cudagraph: batch1→batch8 提升 6.1x
>
> **v3 vs v2 并发倍率：**
>
> - batch1: 1.6x (v2)
> - batch2: 1.6x
> - batch4: 2.1x
> - batch8: **2.7x**（v3_eager） / **16.5x**（v3_cudagraph）



### 5. 多并发 Wall Time（128 tokens 生成）


| Batch Size | v2_eager | v3_eager | v3_cudagraph |
| ---------- | -------- | -------- | ------------ |
| 1          | 3.464s   | 2.210s   | **0.327s**   |
| 2          | 4.089s   | 2.541s   | **0.396s**   |
| 4          | 5.325s   | 2.539s   | **0.406s**   |
| 8          | 7.070s   | 2.579s   | **0.429s**   |


> v3_cudagraph 在 batch=8 时的 wall time 仅 0.429s，而 v2_eager 需要 7.07s，加速比达 **16.5x**。

## 综合对比汇总（Qwen3-0.6B）


| 指标             | v2_eager  | v3_eager  | v3_cudagraph | v3_cg vs v2 |
| -------------- | --------- | --------- | ------------ | ----------- |
| TTFT (256 tok) | 24.2ms    | 20.4ms    | 20.5ms       | **1.2x**    |
| Decode (1 seq) | 37.0 t/s  | 58.0 t/s  | 414.1 t/s    | **11.2x**   |
| Batch=8 E2E    | 144.9 t/s | 397.2 t/s | 2385.0 t/s   | **16.5x**   |
| Init Time      | 7.63s     | 9.92s     | 8.83s        | 0.86x       |
