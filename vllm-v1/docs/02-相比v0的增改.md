# vllm-v1 相对 v0 的改动清单

v1 相比 v0 主要是**把历史 K/V 存下来并管理好**。具体在代码层面，主要新增两个独立包，改了一些既有文件。

## 新增

### `src/kv/`：KV 生命周期管理

| 文件 | 职责 |
| --- | --- |
| `sequence.py` | 一条请求的逻辑状态（token、页表、前缀跳过长度） |
| `pool.py` | 物理页池，页的 free / used / cached 三态 |
| `manager.py` | 订页 / 补页 / 还页的入口 |
| `context.py` | `ForwardContext`：本步访存契约 |
| `prefix/` | 前缀索引：`hash_index.py`、`radix_index.py`、`radix_tree.py`、`hash_util.py`、`noop.py` |

### `src/pagedattention/`：页式读写

| 文件 | 职责 |
| --- | --- |
| `slots.py` | 逻辑区间 → 物理 slot 映射 |
| `store.py` | 按 slot 散射写入，按页表聚合读回 |

## 继承（原样保留）

`layers/activation.py`、`layers/layernorm.py`、`layers/rotary.py`、`sampler.py`、`model_loader.py`、`model_hub.py`

## 改写

| 文件 | 变化 |
| --- | --- |
| `config.py` | 增加 `prefix_backend`、`block_size`、`num_kv_blocks` |
| `model.py` | Attention 增加 `layer_id` 参数 |
| `engine.py` | 接入 KVManager：组装 slot_mapping、绑定 ForwardContext |
| `layers/attention.py` | 走 `PagedStore.write/gather` + SDPA |
| `run.py` | 增加 `--prefix-backend`、`--block-size` |
