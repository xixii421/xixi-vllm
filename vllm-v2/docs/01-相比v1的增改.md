# vllm-v2 新增与改写清单


## 新增

| 路径 | 说明 |
| --- | --- |
| `src/engine/` | Engine 拆包：控制面 / 数据面 / 门面 |
| `src/engine/scheduler.py` | `waiting`/`running`、chunked prefill、`mix_prefill_decode`、preempt |
| `src/engine/model_runner.py` | Prefill 串行 + Decode `[B,1]` 合批；混跑时同一步两次 forward |
| `src/engine/engine.py` | `add_request` / `step` / `generate` / `generate_batch` / `reset_kv` |
| `src/sampling_params.py` | 每请求采样与 `max_tokens` / `ignore_eos` |


## 从 v1 同步并扩展

| 路径 | 变化要点 |
| --- | --- |
| `src/kv/` | 多请求 `SequenceStatus`；admission：`can_allocate` / `can_append` / `may_append` |
| `src/kv/gather.py` | 内部 `_write_kv` / `_gather_kv`（命名与 v1 私有约定对齐） |
| `src/pagedattention/` | 公开 API 同 v1；`write` 支持 decode batch 展平 |
| `src/layers/attention.py` | Prefill chunk（`cached>0`）；Decode 按 batch 维循环 gather→SDPA |
| `src/config.py` | +`max_num_seqs` / `max_num_batched_tokens` / `mix_prefill_decode` |

## 相对 v1 的行为差异

| 能力 | v1 | v2 |
| --- | --- | --- |
| 并发请求 | 1 | ≤ `max_num_seqs` |
| Decode | 单序列 | 合批 `[B,1]` |
| Prefill | 单次吃完剩余 | 可按 budget 切块 |
| Prefill 与 Decode | 同一条请求内先后 | 可同一步混跑（默认） |
| 页争用 | 基本不涉及 | preempt = recompute |
| 前缀 | `none\|hash\|radix` | 同左 |

## 未做的优化
涉及到算子的优化都没有做，包括Fused Prefill和Decode，包括Prefill串行前向，包括Attention算子优化、等等。
